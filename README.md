# aplicacion-diaria

Pedidos diarios del economato: pedidos por proveedor, recordatorios, anotaciones para el día siguiente, personal y rotación de turnos, historial y hojas de pedido imprimibles.

Es una sola página (`index.html`) sin dependencias de compilación. Para usarla, abre `index.html` en el navegador o publícala en cualquier hosting estático (GitHub Pages, Vercel, etc.).

Los datos se guardan en el navegador (`localStorage`, clave `pedidos-v1`), así que cada dispositivo tiene sus propios datos.
